## QUORA
**Answer this question:** How can an online store reduce its return rate without making its return policy stricter?

Start by treating returns as data about your product pages rather than a policy problem. Stricter policies mostly punish customers for information you failed to give them, and they tend to hurt conversion and repeat purchase rates.

Here is the process I use with DTC brands.

1. Sort returns by SKU. In almost every store I audit, a small number of products drive a disproportionate share of returns. In one apparel store doing around $4M a year, a single wide-leg trouser made up 31% of all returns.

2. Sort those SKUs by reason code. "Too small," "not as described," and "color different" each point to a different fix. In that case "too small" appeared 212 times, and the size chart hadn't been updated since launch.

3. Fix the page that sold the item. Typical fixes: a fit note at the top ("runs small, size up"), model height and the size worn, measurements of the garment itself, photos in natural light for color accuracy, and a clear description of fabric stretch or weight.

4. Add the missing information to customer service scripts and post-purchase emails, so people who already bought can still size or use the product correctly.

5. Re-check after 30 to 60 days. If the reason code count for that SKU doesn't drop, the page change didn't address the real cause, so look at reviews and support tickets for the next clue.

A few extras help: surface review snippets about fit near the size selector, and use a sizing tool only if you can keep its data current.

I wrote up the full audit, including the numbers and what we changed, here: https://siavashsed.github.io/ecommerceedge/ecommerce-returns-strategy-reduce-return-rates/

The main point is that your return rate is usually concentrated and fixable, so find the pages responsible before touching the policy.
